# 坦克大战 · TANK BATTLE

经典红白机《坦克大战》（Battle City）的网页重制版。**原生 ES 模块、零依赖、无需构建**，任意静态服务器即可游玩。

## 在线试玩

启用 GitHub Pages 后访问：`https://hnnmmm.github.io/tank-battle/`

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 开火（可按住连发） |
| P | 暂停 |
| M | 静音 |

触屏设备打开页面时会自动显示虚拟方向键与开火按钮。

## 玩法

- 每关 20 台敌军坦克，全部击毁即过关；关卡越高，敌军越强、刷新越快
- 守住中央的**基地（金鹰）**，基地被毁或生命耗尽则游戏结束
- 敌军类型：轻型 / 快车 / 重型（速射）/ 装甲（4 点血量）
- 击毁部分敌军会掉落道具：
  - ★ **火力升级**：高速弹 → 双发 → 可击穿钢板
  - 炸 **全屏爆破**：消灭场上所有敌军
  - 盔 **防护罩**：10 秒无敌
  - 命 **增加生命**
  - 铲 **加固基地**：基地周边砖墙 15 秒内变为钢板
  - 钟 **冻结敌军**：8 秒定身
- 最高分保存在浏览器本地（localStorage）

## 运行

项目使用原生 ES 模块（`<script type="module">`），需通过 HTTP 服务运行（浏览器出于安全限制禁止 `file://` 直接加载模块）：

```bash
cd tank-battle
python3 -m http.server 8000
# 打开 http://localhost:8000
```

无需联网、无需安装任何依赖，也适合直接部署到任意静态托管平台。

## 技术实现

- 原生 ES Modules 分层架构：`config` / `state` / `map` / `audio` / `input` / `logic` / `render` / `hud` / `main`
- 纯原生 JavaScript + Canvas 2D，零第三方库
- 伪 3D 立体渲染：斜面高光、投影、渐变金属 / 水体、辉光粒子与透视棋盘
- 霓虹 / 玻璃拟态 UI，动态星点背景
- 像素风程序化绘制：砖墙、钢板、水域（动态水波）、树林（半透明遮挡）、金鹰基地
- Web Audio API 程序合成音效（需首次交互后生效，符合浏览器自动播放策略）
- 响应式布局：桌面端侧栏 HUD，移动端纵向堆叠 + 触屏按键
- 遵守 `prefers-reduced-motion`，减少动态效果
