# 坦克大战 · TANK BATTLE

经典红白机《坦克大战》（Battle City）的网页重制版。**原生 ES 模块、零依赖、无需构建**，任意静态服务器即可游玩。

## 在线试玩

启用 GitHub Pages 后访问：`https://<你的用户名>.github.io/tank-battle/`

## 操作说明

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 开火（可按住连发） |
| P | 暂停 |
| M | 静音 |

触屏设备打开页面时会自动显示虚拟方向键与开火按钮。

## 玩法

- 每关 20 台敌军坦克，全部击毁即过关；关卡越高，敌军越强、刷新越快
- 守住中央的**基地（金鹰）**，基地被毁或生命耗尽则游戏结束
- 敌军类型：轻型 / 快车 / 重型（速射）/ 装甲（4 点血量）
- 击毁部分敌军会掉落道具：
  - ★ **火力升级**：高速弹 → 双发 → 可击穿钢板
  - 炸 **全屏爆破**：消灭场上所有敌军
  - 盔 **防护罩**：10 秒无敌
  - 命 **增加生命**
  - 铲 **加固基地**：基地周边砖墙 15 秒内变为钢板
  - 钟 **冻结敌军**：8 秒定身
- 最高分保存在浏览器本地（localStorage）

## 运行

项目使用原生 ES 模块（`<script type="module">`），需通过 HTTP 服务运行（浏览器出于安全限制禁止 `file://` 直接加载模块）：

```bash
cd tank-battle
python3 -m http.server 8000
# 打开 http://localhost:8000
```

无需联网、无需安装任何依赖，也适合直接部署到任意静态托管平台。

## 技术实现

- 原生 JavaScript（ES Modules）+ Three.js（WebGL），本地引入 `vendor/three.module.js`，零构建、无需联网
- 分层模块架构，职责清晰、单向依赖：

```
js/
├── config.js   常量与静态数据（关卡地图、坦克种类、道具、金鹰像素图）
├── state.js    全局可变状态（单一数据源）
├── map.js      地图构建、地形查询、碰撞、基地加固
├── audio.js    Web Audio 程序合成音效
├── input.js    键盘 / 触屏映射
├── logic.js    游戏逻辑（移动/碰撞/开火/AI/道具/关卡流程）
├── render.js   Three.js 真 3D 渲染（场景/相机/灯光/模型/特效）
├── hud.js      HUD 数值与覆盖层（菜单/暂停/通关/结束）
└── main.js     入口：装配各模块、绑定 UI、主循环
```

- 真 3D 模型渲染（WebGL）：坦克（车体/履带/炮塔/炮管分件低多边形模型）、砖墙、钢板（铆钉）、水域（波纹动画）、树林（树冠摇曳）、基地金鹰（像素图转 3D 浮雕），并支持实时阴影、方向光/半球光/补光与雾效
- 逻辑层沿用 2D 网格坐标（碰撞/AI/道具），渲染层负责映射到 3D 世界（XZ 平面），保证玩法与画面对齐
- 霓虹 / 玻璃拟态 UI：动态星点背景、玻璃质感 HUD 卡片、霓虹光晕按钮
- Web Audio API 程序合成音效（需首次交互后生效，符合浏览器自动播放策略）
- 响应式布局：桌面端侧栏 HUD，移动端纵向堆叠 + 触屏按键
- 遵守 `prefers-reduced-motion`，减少动态效果
